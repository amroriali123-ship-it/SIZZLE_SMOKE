# 🍔 SIZZLE & SMOKE - Full-Stack Fast Food & Grill Platform

منصة مطعم الوجبات السريعة الفاخرة المتكاملة (Full-Stack) مع واجهة مستخدم استعراضية حديثة ثنائية اللغة (عربي/إنجليزي)، وخادم Express API متكامل مع قاعدة بيانات ونظام مصادقة مشفر، ولوحة تحكم مشرف تفاعلية (Admin Dashboard) لإدارة الوجبات والأسعار والتصنيفات وإعدادات الموقع.

## 1. اختيار التقنية والأسباب

تم اختيار **Node.js + Express REST API** مع بنية بيانات مرنة (تخزين محلي فوري + دعم مباشر لـ MongoDB Atlas عبر Mongoose):

### لماذا هذا الخيار هو الأفضل لموقعك على GitHub Pages؟
1. **استقلالية تامة وتحكم كامل**: يمكنك نشر خادم Express مجاناً على **Render** أو **Railway** مع تفعيل CORS للسماح لموقعك الثابت على GitHub Pages بالاتصال به دون قيود.
2. **أمان عالي للمشرف**: تشفير كلمات المرور باستخدام `bcryptjs`، وتوليد رموز `JWT` آمنة مع تحديد معدل الطلبات (Rate Limiting) لحماية مسارات المشرف.
3. **تكلفة مجانية 100%**: استضافة الواجهة على GitHub Pages (مجاني) + استضافة الخادم على Render Free Tier (مجاني) + قاعدة بيانات مجانية.

## 2. الميزات والخصائص

- **الواجهة العامة للموقع**:
  - ثنائية اللغة بالكامل (العربية RTL والإنجليزية LTR) مع خط Cairo العصري.
  - جلب عناصر القائمة والتصنيفات ديناميكياً من الخادم عبر `/api/menu` مع معالجة حالات التحميل والأخطاء.
  - عرض العناصر المتوفرة فقط (`isAvailable: true`).
  - نظام حجز طاولات تفاعلي ونموذج تقييم لتجارب العملاء.
  - صينية الطلبات (`Order Tray`) ومحاكاة الفاتورة الفورية.

- **لوحة تحكم المشرف (`/admin` أو `#admin`)**:
  - تسجيل دخول آمن ببريد إلكتروني وكلمة مرور مشفرة بـ JWT.
  - لوحة إحصائيات: إجمالي العناصر، المتوفر، المميز، والتصنيفات.
  - إدارة وجبات القائمة (CRUD):
    - إضافة وتعديل وحذف الوجبات مع أسعار بالريال والدولار.
    - إدخال الحقول باللغتين العربية والإنجليزية (الاسم، الوصف، المكونات).
    - رفع الصور من الجهاز أو إدخال روابط خارجية.
    - مفاتيح تبديل فورية لحالة التوفر (`isAvailable`) والتمييز (`isFeatured`).
  - إدارة التصنيفات: إضافة، تعديل، حذف، وإعادة ترتيب التصنيفات.
  - إدارة إعدادات الموقع: تعديل أرقام الهواتف، البريد، العناوين، وساعات العمل وروابط التواصل.

## 3. مخطط قاعدة البيانات

### 1. مستخدم المشرف (`AdminUser`)
- `id`: المعرف الفريد
- `username`: اسم المستخدم (`admin`)
- `email`: البريد الإلكتروني (`admin@sizzlesmoke.com`)
- `passwordHash`: كلمة المرور المشفرة بواسطة bcrypt (10 rounds)
- `createdAt`: تاريخ الإنشاء

### 2. عناصر القائمة (`MenuItem`)
- `id`: المعرف الفريد
- `name_en` / `name_ar`: اسم الوجبة باللغتين
- `description_en` / `description_ar`: وصف الوجبة باللغتين
- `price_sar`: السعر بالريال السعودي
- `price_usd`: السعر بالدولار الأمريكي
- `category`: معرف التصنيف (مرجع)
- `imageUrl`: مسار أو رابط صورة الوجبة
- `ingredients_en` / `ingredients_ar`: مصفوفة المكونات والوصفة
- `isAvailable`: حالة التوفر في الموقع العام (Boolean)
- `isFeatured`: وجبة مميزة / الأكثر طلباً (Boolean)
- `calories`: السعرات الحرارية
- `prepTime`: وقت التحضير بالدقائق
- `spiceLevel`: مستوى الحرارة (0 = عادي، 1 = خفيف، 2 = متوسط، 3 = ناري)
- `createdAt` / `updatedAt`: تواريخ الإنشاء والتعديل

### 3. التصنيفات (`Category`)
- `id`: المعرف الفريد (مثل `cat-burgers`, `cat-chicken`)
- `name_en` / `name_ar`: اسم التصنيف باللغتين
- `sortOrder`: ترتيب العرض الرقمي

### 4. إعدادات الموقع (`SiteSettings`)
- `phone`: رقم الهاتف الموحد
- `email`: البريد الإلكتروني الرسمي
- `address_en` / `address_ar`: عنوان الفروع باللغتين
- `openingHours_en` / `openingHours_ar`: أوقات العمل باللغتين
- `socialLinks`: كائن الروابط (`instagram`, `twitter`, `tiktok`, `facebook`)


## 6. دليل النشر والربط مع GitHub Pages

### الخطوة 1: نشر خادم الواجهة الخلفية على Render (مجاناً)
1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اختر **New +** ثم **Web Service**.
3. اربط مستودع GitHub الخاص بمشروعك.
4. اضبط الإعدادات التالية:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
5. أضف متغيرات البيئة (Environment Variables) في لوحة Render:
   - `NODE_ENV`: `production`
   - `JWT_SECRET`: `ضع_رمز_تشفير_طويل_وعشوائي`
   - `CORS_ORIGIN`: `https://amroriali123-ship-it.github.io`
6. اضغط **Deploy Web Service**. ستحصل على رابط لخادمك مثل:
   `https://sizzle-smoke-backend.onrender.com`

### الخطوة 2: ربط موقع GitHub Pages بالخادم الجديد
في ملف إعدادات الواجهة الأمامية أو في إعدادات البناء:
1. في ملف `.env` الخاص بموقعك:
   ```env
   VITE_API_URL="https://sizzle-smoke-backend.onrender.com/api"
   ```
2. أو يمكنك وضع متغير عام في ملف `index.html`:
   ```html
   <script>
     window.API_BASE_URL = "https://sizzle-smoke-backend.onrender.com/api";
   </script>
   ```
3. أعد رفع الكود إلى GitHub Pages، وسيصبح موقعك يتصل مباشرة بالخادم الحقيقي ويجلب الوجبات والتصنيفات ديناميكياً!

## 7. توثيق مسارات الخادم (API Endpoints)

### المسارات العامة (Public):
- `GET /api/menu` - جلب الوجبات المتاحة للجمهور (يدعم تصفية `?category=...`).
- `GET /api/categories` - جلب التصنيفات مرتبة.
- `GET /api/settings` - جلب بيانات التواصل وساعات العمل.
- `GET /api/stats` - جلب إحصائيات المطعم السريعة.

### مسارات المصادقة (Auth):
- `POST /api/auth/login` - تسجيل دخول المشرف والحصول على رمز JWT (محدد المعدل للحماية).
- `GET /api/auth/me` - التحقق من جلسة المشرف الحالية.

### مسارات لوحة التحكم المحمية (تتطلب `Authorization: Bearer <token>`):
- `GET /api/admin/menu` - عرض جميع الوجبات (المتوفرة وغير المتوفرة).
- `POST /api/admin/menu` - إضافة وجبة جديدة.
- `PUT /api/admin/menu/:id` - تعديل بيانات وجبة.
- `DELETE /api/admin/menu/:id` - حذف وجبة نهائياً.
- `PATCH /api/admin/menu/:id/toggle-available` - تبديل حالة توفر الوجبة.
- `PATCH /api/admin/menu/:id/toggle-featured` - تبديل حالة الوجبة المميزة.
- `GET /api/admin/categories` - عرض كافة التصنيفات.
- `POST /api/admin/categories` - إضافة تصنيف جديد.
- `PUT /api/admin/categories/:id` - تعديل تصنيف.
- `DELETE /api/admin/categories/:id` - حذف تصنيف.
- `GET /api/admin/settings` - عرض إعدادات الموقع.
- `PUT /api/admin/settings` - حفظ إعدادات الموقع.
- `POST /api/admin/upload` - رفع ملف صورة (حتى 5 ميغابايت).
- `POST /api/admin/seed-reset` - استعادة بيانات البذر التجريبية الأولية.
