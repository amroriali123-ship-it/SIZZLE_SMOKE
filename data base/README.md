# 🗄️ دليل ملفات قواعد البيانات (Database Files Guide)

يحتوي هذا المجلد (`data base`) على جميع المخططات والبيانات الجاهزة للاستيراد في مختلف أنظمة قواعد البيانات:

---

## 📂 محتويات المجلد

| اسم الملف | الوصف والنظام المتوافق |
| :--- | :--- |
| **`schema.sql`** | مخطط الجداول والعلاقات والمفاتيح الأجنبية لـ **PostgreSQL**, **MySQL**, **SQLite**, و **Supabase**. |
| **`seed.sql`** | بيانات البذر الأولية (المشرف الافتراضي، التصنيفات، وجبات القائمة، وإعدادات الموقع). |
| **`db.json`** | قاعدة البيانات المستندية المباشرة بصيغة JSON المستخدمة حالياً في خادم Express. |
| **`mongodb_schemas.json`** | مخطط التحقق (JSON Schema Validator) لمجموعات **MongoDB**. |
| **`mongo_seed.json`** | بيانات الوجبات الأولية جاهزة للاستيراد المباشر إلى **MongoDB Compass / Atlas**. |

---

## 🚀 طريقة الاستيراد في قواعد البيانات المختلفة

### 1. الاستيراد في PostgreSQL أو Supabase:
1. افتح **SQL Editor** في لوحة تحكم Supabase أو عبر طرفية `psql`.
2. انسخ محتويات ملف `schema.sql` ونفّذها لإنشاء الجداول والفهارس.
3. انسخ محتويات ملف `seed.sql` ونفّذها لتعبئة البيانات الأولية.

### 2. الاستيراد في MySQL أو phpMyAdmin:
1. أنشئ قاعدة بيانات جديدة باسم `sizzle_smoke`.
2. افتح تبويب **SQL** في phpMyAdmin أو أداة MySQL Workbench.
3. شغّل سكربت `schema.sql` ثم سكربت `seed.sql`.

### 3. الاستيراد في MongoDB (Atlas أو Compass):
1. في أداة **MongoDB Compass** أو لوحة **MongoDB Atlas**:
2. أنشئ قاعدة بيانات باسم `sizzle_smoke` ومجموعة باسم `menu_items`.
3. اضغط على **Add Data** > **Import File** واختر ملف `mongo_seed.json`.

### 4. الاستخدام المباشر مع خادم Express الحالي:
ملف `db.json` هو الملف الفعلي الذي يقرأ منه الخادم ويكتب إليه بشكل فوري وذري عند إجراء أي عمليات إضافة أو تعديل أو حذف (CRUD) من لوحة تحكم المشرف.
